# 功能测试

这里只保留需要持续维护的功能和数据安全测试。测试按模块组织；不保存复审轮次、提交版本对应的临时复现、诊断日志或构建产物。

在仓库根目录运行：

```sh
pnpm test
# 单独运行一个模块：
node --test tests/requests.test.mjs
# C2 真实 React/DOM 键盘与焦点回归（需已安装 Chrome / Edge / Chromium）：
pnpm test:c2
```

| 文件 | 必要覆盖 |
| --- | --- |
| `chat.test.mjs` | 用量提交与失败恢复、账户隔离、共享附件、备份草稿/原件/设置、未知模型导入与缓存 |
| `storage.test.mjs` | 并发重命名、中途加载、删除/替换历史后的旧异步回调 |
| `models.test.mjs` | 模型图片能力限制、持久化模型与思考强度的输入校验 |
| `requests.test.mjs` | 图片缩放及上传表单、文档 20/21 聚合守卫、缺失附件选择、再次解析授权/取消、purpose 与新旧备份、原图保留、回复链接过滤 |
| `attachment-policy.test.mjs` | 上传前计费确认取消、选择文字解析、导入期间守卫、重新解析/缺失附件按钮的实际请求路径 |
| `upload-lifecycle.test.mjs` | 排队停止、共享任务使用权、迟到成功结果与部分成功保存、旧解析提示快照、缓存/任务复用及失败后重新授权 |
| `attachment-view.test.mjs` | MIME/SVG 处理、URL 生命周期、文件交付、图片查看器与浮层行为 |
| `native-files.test.mjs` | 分享文件身份、分块字节、写入/清理失败恢复、启动清理与并发分享 |
| `settings.test.mjs` | 设置分组的界面点击与程序导航 |
| `platform.test.mjs` | Android 返回层级与外链/引用点击 |
| `perf.test.mjs` | C0 夹具计数与分支、确定性数据、空库注入与事务失败、长任务和帧间隔统计口径 |
| `rich-gate.test.mjs` | C1 富内容门控：屏外不执行高亮/语言包/图表/公式排版、进入或聚焦后增强并保留、流式立即渲染且结束后不回退、Mermaid 队列最新优先与取消/失败隔离 |
| `accessibility-browser.test.mjs` | C2 独立浏览器：主 CSS HTTP 200/规则/实际样式守卫、逐例页面隔离；弹窗与菜单键盘/指针、会话与设置、引用、状态/快速失败/历史分支、图片长名横屏 200%、抽屉遮罩、来源面板、320px/大字体和 coarse pointer 44px |

`helpers/entries/` 只负责导出被测生产模块；`helpers/runtime/` 提供存储、浏览器和平台边界替身。`helpers/compile.mjs` 共用项目现有 Rspack，将测试编译到系统临时目录中的独立子目录，在测试结束后自动清理，不向项目 `tmp/` 写入。测试不安装依赖、不读取用户凭据、不调用真实 API。

当前常规回归共 **115 项**，`pnpm test:c2` 另有 **17 项**真实浏览器回归。存储测试可控制事务提交顺序及失败；图片测试只模拟解码/canvas 边界；平台测试检查参数和字节。C0 工具测试校验夹具、统计口径、备份重编号后的分支语义及尾部就绪探针（含 v4 末轮就绪只等可见富内容、屏外门控块不计入），设备测量另见 C0 记录；C1 富内容门控测试编译真实门控/调度器/组件，仅替换 react、prismjs、mermaid 包与高亮/公式服务替身。这些覆盖不代表真机、真实 React 调度、Android 接收应用或真实 API 验证。

新增测试文件时需更新 `package.json` 的 `test` 命令。保留明确的文件列表，保证 Windows 与 CI 使用相同的测试入口。

`test:c2` 使用单独的临时浏览器配置、离线合成会话和真实 React/DOM；不加载日常浏览器配置，并阻止外部 HTTPS 请求。通过 `C2_BROWSER` 可指定浏览器可执行文件；未找到浏览器会明确失败，不静默跳过。该套件在项目 `tmp/c2-browser-build-*` 与 `tmp/c2-browser-profile-*` 中生成独立产物，结束后检查路径并清理。200% 用例将已计算字号/行高放大两倍，Android 系统字体效果仍由模拟器/设备另测。它不属于默认 `pnpm test`，避免现有 Node CI 被额外的浏览器安装要求阻塞；TalkBack 人工阅读、触控和系统浮层仍需设备验收。

C2 review 修复后，主 CSS 输出/引用名固定为同一个名称，检查真实 HTTP 成功、规则非空和应用布局样式；说明文字使用稳定标记且匹配数不足时失败。每例重新加载页面并恢复视口/触控/动画模拟，避免失败浮层污染下一例；指针事件前用 elementFromPoint 确认目标未被覆盖。可设置 C2_ARTIFACTS=tmp/某个独立目录 保存诊断截图和观察数据（只允许工作区 tmp 下）。首次 12/12 的 CSS 404 结果已在阶段 C 记录中撤回其带样式布局证明。
